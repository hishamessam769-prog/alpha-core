# ALPHA PLATFORM V3.7.1

تحديث إضافي فوق V3.7 يضيف:

- نصوص Push ديناميكية حسب اسم السهم والمحفظة والشهر والأداء الفعلي.
- Deep Links دقيقة إلى المحفظة أو التوصية المرتبطة.
- عرض مدة التوصية والعائد حتى الآن مباشرة على كروت التوصيات.

## التشغيل

1. شغّل `upgrade-v3.7.1.sql` في Supabase SQL Editor بعد V3.7.
2. ارفع ملفات المشروع إلى GitHub واترك Vercel يعمل Deploy.
3. لا تغيّر مفاتيح VAPID الحالية.

لا توجد تغييرات في الجداول الأساسية أو الحسابات أو الـRoutes.
