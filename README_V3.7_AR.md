# ALPHA PLATFORM V3.7

تحديث إضافي فوق V3.6.1 يضيف:
- إشعارات تلقائية للتوصيات والمحافظ والتقارير وتحديثات الأداء.
- اختيار Notify subscribers قبل النشر.
- روابط مباشرة Deep Links.
- Notification Inbox لكل مستخدم مع عداد غير المقروء.
- Digest تلقائي عند وجود عدة تحديثات معلقة في نفس الدفعة.

## التشغيل
1. شغّل `upgrade-v3.7.sql` في Supabase SQL Editor مرة واحدة.
2. ارفع ملفات المشروع إلى GitHub؛ Vercel سيعمل Deploy تلقائيًا.
3. لا تغيّر مفاتيح VAPID الحالية طالما الإشعارات تعمل بالفعل.
