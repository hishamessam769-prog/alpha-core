# ALPHA CORE V2.1

نسخة تطوير مباشرة فوق الـMVP الحالي وتستخدم نفس مشروع Supabase ونفس الجداول والبيانات الموجودة بالفعل.

## الجديد في V2.1

- تصميم Landing Page وتجربة مستخدم أوضح.
- ست بطاقات أداء داخل لوحة الأعضاء:
  - أداء المحفظة خلال الشهر.
  - أداء EGX30 Capped خلال الشهر.
  - الألفا الشهرية.
  - أداء المحفظة التراكمي.
  - أداء المؤشر التراكمي.
  - الألفا التراكمية.
- حساب الأداء التراكمي بطريقة التركيب الشهري.
- الجراف يعرض نقطة واحدة فقط لكل شهر منشور. تحديثات الشهر الحالي تغير نفس النقطة ولا تضيف نقاط يومية كثيرة.
- فلاتر 3M و6M و1Y وALL.
- إظهار آخر تحديث وحالة الشهر LIVE أو FINAL.
- تحسين ترتيب لوحة العضو: الأداء ثم الجراف ثم المحفظة ثم السجل والقرارات.
- دعم العربية والإنجليزية مع اتجاه RTL للعربية.
- صفحة Profile لتعديل الاسم واللغة والـNewsletter.
- تحسين تصدير PDF وتقسيم التقرير على أكثر من صفحة عند الحاجة.
- تحسين لوحة الإدارة مع الحفاظ على نفس طريقة إضافة الشهر والأسهم والنشر والإغلاق.
- تصميم Responsive للموبايل والتابلت والكمبيوتر.

## قاعدة البيانات

لا تحتاج V2.1 إلى تشغيل SQL جديد. النسخة تستخدم نفس قاعدة البيانات بعد تشغيل upgrade_mvp_v1.sql الذي تم تشغيله سابقًا.

## متغيرات Vercel المطلوبة

لا تغيرها إذا كانت موجودة بالفعل:

- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY

## التحديث على GitHub

ارفع محتويات هذا المجلد إلى نفس Repository القديم واستبدل الملفات الموجودة. عند اكتمال الرفع سيبدأ Vercel Deployment تلقائيًا.
