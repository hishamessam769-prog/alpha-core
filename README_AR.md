# ALPHA CORE V2.3

نسخة تطويرية فوق V2.2 وتحافظ على نفس Supabase ونفس المستخدمين والبيانات.

## المزايا
- محافظ متعددة.
- توصيات مستقلة مبنية على التحليل الأساسي.
- قرار Invest أو Hold / Wait مستقل عن حالة Open أو Closed.
- Potential Upside واضح على كروت التوصيات.
- أداء السهم والمؤشر وAlpha والمدة.
- سجل تحديثات لكل شركة.
- تقارير أسبوعية مع لوحة Admin.
- رفع أسعار Excel للمحافظ والتوصيات المفتوحة.

## التحديث
1. شغّل `supabase/upgrade_v2_3.sql` مرة واحدة في نفس مشروع Supabase.
2. ارفع ملفات المشروع على نفس GitHub Repository.
3. Vercel سيعمل Deploy تلقائيًا.
